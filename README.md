# Requisitos Funcionais

RF01: O sistema deve permitir que o avaliador realize login utilizando e-mail e senha.

RF02: O sistema deve permitir que o avaliador visualize somente as avaliações realizadas por ele.

RF03: O sistema deve permitir que o avaliador cadastre novos avaliados.

RF04: O sistema deve permitir que o avaliador edite os dados dos avaliados cadastrados por ele.

RF05: O sistema deve permitir que o avaliador exclua avaliados cadastrados por ele.

RF06: O sistema deve permitir que o avaliador registre novas avaliações para um avaliado.

RF07: O sistema deve permitir que o avaliador edite avaliações já registradas, incluindo seus resultados.

RF08: O sistema deve permitir que o avaliador exclua avaliações registradas por ele.

RF09: O sistema deve calcular automaticamente as classificações dos resultados conforme as tabelas de referência do PROESP-BR.

RF10: O sistema deve apresentar os resultados dos testes e as respectivas classificações nas avaliações consultadas.

RF11: O sistema deve permitir que o avaliador exporte os dados das avaliações para arquivos em formatos de planilha, como XLS, XLSX ou ODS.

RF12: O sistema deve permitir que o avaliador gere relatórios individuais em formato PDF.

RF13: O sistema deve permitir que o usuário acesse uma área de ajuda com orientações sobre o uso do aplicativo.

RF14: O sistema deve permitir que o usuário consulte a política de privacidade e as informações sobre o tratamento dos dados pessoais.
